# MyProblem brand icons

Source pack: AI ticket icon exports (PNG). Staged for website + future Android/iOS apps.

| Path | Use |
|---|---|
| `../public/favicon.ico` | Browser tab |
| `../public/icons/` | Web size ladder + master art |
| `../public/og.png` | Open Graph / social |
| `../src/app/icon.png` | Next.js metadata icon |
| `../src/app/apple-icon.png` | Apple touch (Next) |
| `android/res/mipmap-*/` | Drop-in Android launcher icons (not published yet) |
| `ios/` | iOS AppIcon sizes |
| `store/google-play-512.png` | Play Store listing |

Notes from pack README: web icons have rounded transparent corners; Android adaptive preview is **not** a separated foreground layer.
