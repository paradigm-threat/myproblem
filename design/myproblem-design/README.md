# MyProblem × CleverTree — The Open Commons

Design handoff based on the supplied founder sentiment. This is a proposed design system, not a live-site audit or tested application.

- `content/brand-and-pages.md`: brand brief, page copy, governance and component guidance
- `styles/tokens.css`: complete light/dark/system palettes, independent room scope
- `styles/globals.css`: layout, typography, controls and motion
- `theme/bootstrap.js`: pre-paint site preference
- `theme/controller.ts`: independent preference controller
- `icons/`: four signature SVGs and standard icon inventory
- `art/prompts.md`: eight illustration prompts plus dark variant modifier
- `content/implementation.md`: accessibility and engineering checklist

The original chat's interactive previews and reference images are not included as production assets. No live IRC endpoint, fee cap, operator agreement or privacy policy has been verified. The starter code needs integration and testing.
