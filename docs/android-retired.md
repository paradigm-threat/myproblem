# Android APK retired (MyProblem)

MyProblem no longer ships a standalone Android app. Phone chat lives in **Clevertree Chat** (`clevertree-chat` repo: `:clevertree-app` on the `clevertree-room` AAR). This site embeds the room on the web only.

**Archive (do not lose):** git tag `archive/android-testmode-2026-11-27` on this repo (GitLab + GitHub). Restore with:

```bash
git checkout archive/android-testmode-2026-11-27 -- apps/android-testmode
```

See Clevertree docs: `docs/android-app.md` · `docs/android-room.md` in the clevertree-chat repository.
