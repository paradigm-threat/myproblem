Canonical KB article: [`../../myproblem-kb/general/web/set-up-website-nearly-free.md`](../../myproblem-kb/general/web/set-up-website-nearly-free.md).

## What is true today (KB)

1. **Step 1 — Host + domain:** Use a generous free deploy host such as **Vercel’s free plan** (what MyProblem’s own marketing site uses — enough for a typical personal/small site within plan limits). Register the domain **on Vercel** or register elsewhere and **park/point DNS to Vercel**.  
2. **Step 2 — LLM build/deploy/maintain:** An LLM can implement the site, including database, SEO, forms, and ongoing fixes — without a locked $100s/yr brand front-end.  
3. **Heavy compute when needed:** **Rackspace Spot** (and similar) + **MCP**/agent tooling runs expensive hardware **cheaply and only while needed**.

Main recurring cost for many people: **the domain**, not a proprietary website jail.

Always **re-check live free-tier limits** — we cite vendors; we do not cache their pricing pages in the KB ([`knowledge-base.md`](./knowledge-base.md)).
